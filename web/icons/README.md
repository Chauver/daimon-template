# Icônes de l'appli (Δaï)

Dépose ici les 4 PNG exportés depuis Claude Design, **avec ces noms exacts** :

| Fichier | Taille | Usage |
|---|---|---|
| `icon-1024.png` | 1024×1024 | source / stores (réserve) |
| `icon-512.png`  | 512×512   | manifest PWA (`any` + `maskable`) |
| `icon-192.png`  | 192×192   | manifest PWA |
| `icon-180.png`  | 180×180   | `apple-touch-icon` (écran d'accueil iOS) |

Ce sont des **carrés** : iOS et Android arrondissent d'eux-mêmes. Une fois déposés,
recharge l'appli — l'icône apparaît à l'installation (« Sur l'écran d'accueil »).
